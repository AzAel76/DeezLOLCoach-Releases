LoL Coach 0.4.0: style options

Three looks for the same screens, built from the tester's answers to the first mockups. Each shows the champ select page (which now opens by itself) with the item set, and the phase card in that style. All data is example data. Made 2 October 2026 against v0.3.4.

Crest icon, refined

The first crest lost its whistle below 32 px. These variants make the whistle bigger and simpler, so it still reads in the tray and taskbar. C2 drops the inner border at small sizes; C3 fills the crest gold and makes the whistle dark.

Phase card in Clean Light: a light frosted panel. Over the dark map, a light panel stands out more, which is good for glances and less good for blending in. The overlays could stay dark while the main window is light.

What to pick

  1. Style: 1 Fluent Dark, 2 Hextech or 3 Clean Light? Mixing is possible, such as Hextech headings on Fluent Dark.
  2. Crest: C1, C2 or C3?
  3. Item set: layout A (4 core + boots + 2 situational with "when to buy" notes) or layout B (3 core + boots + 3 situational slots)?

My recommendation: Fluent Dark for the main window (it looks native, which was the original ask) with C2, and layout A, because the "when to buy" notes are where the coaching is.
